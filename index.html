Products I build and run myself

Six live products, each built end to end on my own time: the agents, the data, the interface and the deployment. All self-hosted on Coolify behind Cloudflare.

Footbolski

Weekly football, Kraków · in use every week since May 2026

Runs a pickup game for about 20 players: waitlist, payment tracking, WhatsApp reminders. The hard part is fair teams, and that turned out to be a search problem, not a writing task.

The first version asked Claude for teams and reasoning in one go. Now Claude rates the players inside a LangGraph flow, an exhaustive solver builds the teams, and Claude explains the final split.
